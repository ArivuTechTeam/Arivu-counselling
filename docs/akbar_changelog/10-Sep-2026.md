# 10-Sep-2026

## fix/ai-threadpool-contention

1.

   - Before: It was hypothesized that one long AI generation request could starve an unrelated student's dashboard request in FastAPI's shared sync threadpool.
   - After: A repeatable two-account ASGI benchmark measured a 2.05 ms median dashboard baseline and 2.06 ms during a concurrent 500 ms generation handler, a 0.01 ms difference; the single-request bottleneck was not confirmed.

2.

   - Before: Converting the full synchronous AI/database pipeline to async or increasing Uvicorn workers was proposed without measured evidence that either change would improve this scenario.
   - After: Production concurrency remains unchanged because one generation uses only one of AnyIO's 40 default worker tokens; avoiding an unproven worker increase is safer for the current timeline, while the committed benchmark can detect a future regression.

3.

   - Before: Findings #3 (super-admin aggregation) and #5 (missing indexes) were identified alongside the current performance work.
   - After: Both findings remain explicitly pending for the requested follow-up round and are unchanged on this branch.
