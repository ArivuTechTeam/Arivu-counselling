# 17 September 2026

## Super-admin wiring and scalability

- Institution onboarding now refreshes the institution and administrator
  directories immediately without a browser reload.
- Super admins can safely rename, change the plan for, activate, or deactivate
  an institution. Permanent tenant deletion remains intentionally unavailable.
- The platform question bank now reports approved, pending, needs-edit, and
  rejected counts instead of implying every counted question is approved.
- Platform overview, question-bank, and AI-quality aggregates move into
  service-role-only PostgreSQL functions in migration 36, avoiding full-table
  transfers into the API process.
- Super-admin API responses now use strict Pydantic response models.
- Local backend configuration explicitly uses development mode and the
  documented frontend port 3001.
